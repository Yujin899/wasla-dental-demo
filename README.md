# وصلة | Wasla dental demo

A single-page Arabic RTL demo of a proposed dental patient/student matching idea in Tanta. Wasla is a placeholder name.

## Run
Open `index.html` in a browser. HTML, CSS and JavaScript are in one file. No installation, build or backend is required. Cairo loads from Google Fonts, with system fallbacks when offline.

## Demo only
The forms validate fields and show a demo confirmation. Data is not sent or stored. No appointment is made. Use fictional data only.

There is no university partnership, guaranteed treatment, diagnosis or fixed-price promise. Any future treatment requires assessment and college/supervisor approval.

Before real registration, add a secure backend, appropriate privacy/consent flow, restricted access, an operating contact and confirmed college approval. Do not collect medical documents in a public repository.

## Deployment
GitHub Pages is configured to publish from `main`, `/ (root)`. All application code is static.
